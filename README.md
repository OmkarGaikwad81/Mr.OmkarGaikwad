# Omkar Gaikwad | Portfolio Website

This is the personal portfolio and digital resume for **Omkar Gaikwad**, an Integration Engineer specializing in Healthcare IT and Telecom domains.

## 🚀 Features

*   **Responsive Design**: Built to look great on mobile, tablet, and desktop devices.
*   **Modern Aesthetics**: "Professional Tech" theme with a clean, dynamic interface.
*   **Dual Theme Support**: 
    *   🌞 **Light Mode**: Vibrant "Soft Medical Tech Sky Blue" palette.
    *   🌙 **Dark Mode**: Sleek Deep Navy Blue for reduced eye strain and professional presence.
    *   Theme preference is automatically saved using `localStorage`.
*   **Interactive UI**: Smooth scroll animations and interactive hover effects on skill cards and action buttons.
*   **Resume Capabilities**:
    *   📥 Direct official `Resume.pdf` file download.
    *   🖨️ Native "Print as PDF" integration that temporarily strips away non-essential UI components to generate a clean, ATS-friendly document directly from the browser window.

## 🛠️ Technologies Used

*   **Core**: HTML5, Vanilla JavaScript
*   **Styling**: Tailwind CSS (loaded via CDN for maximum portability)
*   **Icons**: Inline standard SVGs

## 📁 Project Structure

*   `index.html`: The main structural entry point containing all website content, semantic tags, and Tailwind utility classes.
*   `styles.css`: Custom CSS containing animation keyframes and standard overrides.
*   `script.js`: Core interactivity logic handling the Intersection Observer (scroll animations), sticky header adjustments, Dark/Light Mode toggling, and PDF generation scripts.
*   `profile.jpg`: The hero section display picture.
*   `Resume.pdf`: The official resume placeholder file supporting the direct download button.

## 💻 How to Run Locally

Because this project is built deliberately as a lightweight static asset site, there is no build step (like npm/Node) required to view it.

1.  Download or clone this repository to your local machine.
2.  Open the folder containing the project files.
3.  Double-click `index.html` to open it instantly in your default web browser.

That's it!
